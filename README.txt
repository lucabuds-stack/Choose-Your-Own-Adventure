To run the game, you will require a web browser (e.g Google Chrome).
Preferably with the latest technology, although only needs to support things like <dialog> or <button> which are more modern.
You do not require an internet connection to run the game, although it is required to download the game (obviously).

Open the game by double clicking/running index.html.
If nothing happens, right click, open with, then open it with your browser.
If it asks what to open the file with, select your browser.

Opening the other files will probably result in nothing, except maybe a virus on your PC (Just kidding).
